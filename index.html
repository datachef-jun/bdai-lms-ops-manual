어드민 왼쪽 탭 기준으로
보는 운영진 메뉴얼

운영 어드민(/admin/) 왼쪽 탭이 업무 구역입니다. 이 문서는 탭마다 무엇을 관리하는지를 개괄적으로 설명합니다.

대상: 신규 운영진 버전: v0.4 구조: 왼쪽 탭 = 목차

1. 시작

LMS가 하는 일

학회원이 수업·과제·출결·공지·행사를 쓰고, 운영진이 그 상태를 승인·반영·검수하는 학회 운영 플랫폼입니다.

공간누가경로
학회원 포털학회원/regular/, /notices/ 등
강사 포털담당 강사/instructor/
운영 어드민운영진 (공용 계정)/admin/

어드민 접속

  1. 공용 운영 계정으로 로그인
  2. /admin/ 이동
  3. Slack 6자리 인증번호 입력
  4. 왼쪽 탭에서 업무 구역 선택
운영 어드민은 공용 계정 하나로 사용합니다. 비밀번호 외부 공유 금지. 공유 PC에서는 사용 후 로그아웃. 중요한 승인·점수 변경은 팀 채널에 처리자를 남깁니다.
화면 조작이 막히면 어드민 Daybear에서 키워드 검색 (출석, 상벌점, 모집…).

3. 탭대시보드·지표

목적: 현황 파악 대표: /admin/dashboard/
이 탭에서

분반을 하나씩 열지 않고, 제출률·출석률·행사 신청 등 숫자를 먼저 봅니다.

화면보는 것
운영 현황가입·승인·로그인 등 전체 지표
정규반 운영분반·주차별 출석률·과제 제출률
정규반 라인업기수별 분반·강사·주차 구성
행사 신청행사별 신청·승인·정원 달성
조별활동·중도이탈이탈·벌점 현황
주간 점검의 출발점은 정규반 운영 대시보드입니다. 이상 분반을 찾은 뒤 정규반·일상 운영 탭으로 들어가 처리합니다.

4. 탭일상 운영

목적: 매일·매주 반복 작업 CSV · 지급 · 승인 큐
이 탭에서

데이터를 일괄 반영하고, 사람이 판단해야 하는 대기 건을 처리합니다.

일괄 반영

메뉴목적학회원에게
출석 CSV 수업 출석 일괄 반영 분반 출결 탭 갱신
상벌점 CSV 상점·벌점 일괄 반영 총점 갱신 (수료 기준과 연결)
정규반 CSV 수강(Enrollment) 배정 정규반 홈에 분반 카드 노출
B포인트 지급 이벤트·보상용 포인트 (상벌점과 별개) B포인트 잔액 반영

승인 대기열

큐승인하면
강의·클래스 심사Learning에 강의 공개
WAVE·원데이·JOB 심사단편 콘텐츠 공개
강의 VOD 입금유료 강의 접근 개방
자소서·포트폴리오 첨삭첨삭 요청 진행/반려
후기·피드백 티켓 입금 등혜택·권한 부여
담당이 있는 큐는 임의 승인하지 않습니다. CSV는 소수 행 테스트 → 본 업로드 → 건수 검수.

5. 탭회원·권한

목적: 이용 자격 관리 /admin/accounts/user/
이 탭에서

누가 LMS를 쓸 수 있는지, 어떤 회원 유형인지 정합니다. 분반 배정 전 단계입니다.

  • 회원 상태 — 승인 대기 / 승인 / 거절
  • 회원 유형 — 정규반, 일반, 게스트, MOU 등 (보이는 기능이 달라질 수 있음)
  • 관련 — 강사 신청, 현직자 신청, 블랙리스트, 연사 후보
학회원

승인 전에는 대기, 승인 후 포털 이용. 분반 배정은 정규반 탭(수강)에서 이어서 합니다.

운영진

승인·유형 오류는 “수업이 안 보여요” 문의로 이어집니다. 개인 계정에 스태프 권한을 함부로 주지 않습니다.

6. 탭정규반

목적: 기수·분반 수업 운영 핵심 탭
이 탭에서

분반, 수강, 출결, 과제, 상벌점, 조별활동, 블로그 챌린지를 관리합니다. 학회원 /regular/ 화면에 바로 연결됩니다.

주요 메뉴

메뉴하는 일
분반 (ClassGroup)기수·분반·Zoom·자료·과제 설정
수강 (Enrollment)회원을 분반에 배정 · CSV 업로드
출석 / 출결 사유출석 반영, 사유폼 검토
과제·제출과제 정의, 제출 현황
상벌점점수 기록 확인·수정 (CSV는 일상 운영에도 있음)
조별활동팀 매칭, 일지·채점, 조장·이탈 점수
블로그 챌린지주제 등록, 제출 승인(스탬프)
정규반 운영 대시보드분반별 출석·제출률 이상치

출결 · 상벌점 · B포인트 구분

항목의미
출석그 주 수업 참여 기록. Zoom 또는 CSV로 반영
상벌점수료용 총점. 규정에 따른 가산·감점
B포인트수료 총점과 별개 보상 재화 (일상 운영에서 지급)
사유폼·수기 출석은 Zoom/CSV 재업로드에 덮이지 않는 경우가 많습니다. 벌점 자동 정리는 시간차가 있을 수 있습니다.

주간 흐름 (짧게)

때할 일어디
수업 전 Zoom·자료·과제 안내 노출 확인 정규반 → 분반
수업 직후 출석 반영 (Zoom 또는 CSV) 일상 운영 / 정규반
당일~익일 출결 사유폼 검토 정규반 → 출결 사유
주중 상벌점 수동 반영, 미제출 안내 일상 운영 · 정규반
주 1회 출석률·제출률 이상 분반 확인 후 안내 대시보드 → 정규반 운영

시즌 메뉴 (정규반 안)

조별활동

팀 구성·일지·채점. 조장 상점 / 중도이탈 벌점.

블로그 챌린지

주차별 주제 → 제출 → 스탬프 승인. 보너스 상점은 시즌 정책 확인.

7. 탭커뮤니티

목적: 공지·행사·게시판 학회원 /notices/, /qna/
이 탭에서

공지 게시, 행사 신청 받기, 승인·안내, QnA 관리.

흐름내용
1. 공지 작성행사면 신청 기간·정원·Zoom 설정
2. 신청 처리승인 / 대기 / 취소
3. 현황대시보드·지표 → 행사 신청
4. 안내Zoom·채팅 초대 메일 등 일괄 발송

9. 탭BDAI Form

구글폼 대체 공개 링크 /f/…/
이 탭에서

내부 폼을 만들고, 로그인 없이 받을 수 있는 공개 링크로 응답을 받아 승인·집계합니다.

  1. 폼·문항 구성 → 접수 중 ON
  2. 화면의 전체 공개 URL 복사·공유
  3. 응답·승인 → 응답 대시보드로 집계

12. 문의

  1. 왼쪽 탭 → 하려는 일의 구역인지 확인
  2. Daybear에서 키워드 검색
  3. 담당자에게: 목적 한 줄 + URL + 한 일 + 결과/오류 문구
예: “출석 CSV 12건 중 2건 ‘회원 없음’. URL …/import-csv/. 해당 이메일은 승인 회원으로 보임.”
