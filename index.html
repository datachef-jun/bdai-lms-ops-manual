사이트 탭 + 어드민
사용법 메뉴얼

학회원 화면(bdai.co.kr 상단 탭)을 기준으로, 각 탭마다 어드민에서 어디를 열고 무엇을 하면 되는지를 상세히 정리합니다.

대상: 신규 운영진 화면 캡처 + 어드민 절차 공용 계정

1. 시작

운영진이 알아야 할 구조

LMS는 사이트(학회원 화면)와 운영 어드민으로 나뉩니다. 사이트에서 보이는 상태(분반, 출석, 점수, 공지, 신청)를 어드민에서 만들고 고칩니다.

공간용도경로
사이트수업·공지·knock 등 이용bdai.co.kr
강사/현직자 포털담당 수업·현직자 기능/instructor/
운영 어드민승인·출결·점수·공지 관리/admin/

어드민 접속

  1. 공용 운영 계정으로 로그인
  2. /admin/ 이동
  3. Slack 6자리 인증 입력
운영 어드민은 공용 계정 하나로 사용합니다. 공유 PC에서는 사용 후 로그아웃. 중요 승인·점수 변경은 팀 채널에 처리자를 남깁니다.

3. 대시보드 (로그인 홈)

/dashboard/ 사이트 홈
화면 목적

로그인 직후 요약 화면입니다. 배너·알림·수강 중 분반 바로가기가 모입니다.

이 화면에서 확인할 것

  • 알림 — HR 패스, B포인트 등 미확인 건
  • 나의 정규반 — 수강 배정된 분반 카드 (출석 요약 포함)
  • 분반이 안 보이면 → 회원 승인 또는 수강(Enrollment) 미배정
어드민에서

대시보드에 분반·배너·알림이 맞게 보이게 하려면

대시보드 자체는 별도 “편집 화면”이 아니라, 아래 데이터가 모여 보이는 요약입니다.

1) 「나의 정규반」이 비어 있을 때

  1. 어드민 왼쪽 회원·권한 → 회원 목록에서 해당 계정 승인 상태 확인
  2. 왼쪽 일상 운영 또는 정규반 → 정규반 CSV 업로드로 수강(Enrollment) 배정
  3. 배정 후 사이트 대시보드를 새로고침해 분반 카드가 뜨는지 확인
/admin/accounts/user/ · /admin/regulars/enrollment/import-csv/

2) 상단·대시보드 배너

  1. 왼쪽 광고·제휴 또는 대시보드·지표 → 광고 배너 및 예산 대시보드
  2. 지면(대시보드 등)·노출 기간·이미지를 확인·수정
  3. 실험 중이면 BDAI × BDAIB에서 A/B가 대신 노출될 수 있음

3) 알림·B포인트

  • B포인트 지급: 일상 운영 → B 포인트 지급
  • HR 패스 등: Knock 관련 메뉴 (담당 확인)

4. B.D.A.I

드롭다운 AI 기업분석 · AI 캠퍼스맵
탭 목적

취업·학교 생활 정보 영역입니다. 정규반 주간 운영과 별도 담당인 경우가 많습니다.

어드민에서

B.D.A.I 탭 운영 방법

왼쪽 탭 AI 기업분석 · AI 캠퍼스맵 · (현황) 대시보드·지표

AI 기업분석

  1. 왼쪽 AI 기업분석 허브를 연다
  2. 기업·리포트 데이터 추가/수정은 해당 모델 목록에서 처리
  3. 회원이 넣은 커피챗 관심 신청은 대시보드·지표 → AI 기업분석 · 커피챗 신청 (또는 같은 허브 내 신청 목록)에서 pending 확인
  4. 매칭·상태 변경 후 필요 시 메일/문자 안내
knock의 「커피챗」공개 일정과, 기업분석 「관심 신청」DB는 별개일 수 있습니다. 문의가 오면 어느 경로인지 먼저 확인하세요.

AI 캠퍼스맵

  1. 왼쪽 AI 캠퍼스맵 또는 대시보드·지표 → AI 캠퍼스맵 운영
  2. 학교별 장소·이미지·제휴 매장 등록/수정
  3. 학회원 리뷰·추가 요청이 있으면 같은 허브에서 검수

5. 정규반

핵심 탭 /regular/ · /regular/classes/…
탭 목적

기수·분반 수업의 중심입니다. 캘린더·공지와 분반 상세(총점·출석·과제·Zoom·자료)가 여기에 있습니다. 운영진 주간 업무의 대부분이 이 탭과 연결됩니다.

5-1. 정규반 홈

학회원 화면

  • 수업·일정 캘린더
  • 정규반/조별활동 공지 목록
  • 분반 진입은 대시보드 「나의 정규반」또는 분반 링크

운영진

  • 공지 내용·일정 노출이 맞는지 수업 전 확인
  • 어드민: 정규반 / 커뮤니티(공지)

5-2. 분반 상세 (수업·출결·점수)

학회원에게 보이는 핵심

  • 내 현재 상태 — 총점(상점/벌점), 수료 여유, 이번 주 출석, 과제 미제출
  • 이번 주 해야할 것 — 등록된 과제·수업
  • 수업 탭 — Zoom 링크, 수업자료, 노트
  • 출결·상벌점 상세 링크
어드민에서

정규반 탭 — 상세 운영 절차

주로 쓰는 왼쪽 탭: 정규반 · 일상 운영 · 회원·권한 · 대시보드·지표

A. 회원 승인 (분반 배정 전)

  1. 왼쪽 회원·권한 → 회원 목록
  2. 승인 대기 회원을 찾아 상태 승인, 유형(정규반 등) 맞춤
  3. 개인 학회원 계정에 스태프 권한은 주지 않음 (어드민은 공용 계정 사용)
/admin/accounts/user/

B. 수강 배정 (Enrollment) — 「나의 정규반」에 카드가 뜨게

  1. 왼쪽 일상 운영 또는 정규반 → 정규반 CSV 업로드
  2. 기수·분반·회원 식별값(이메일 등)이 어드민 분반/계정과 일치하는지 확인
  3. 소수 행으로 테스트 업로드 → 결과 메시지 확인 → 본 업로드
  4. 수강·분반 목록에서 인원 수 검수
/admin/regulars/enrollment/import-csv/

C. 분반 설정 (Zoom·자료·과제)

  1. 왼쪽 정규반 → 분반(ClassGroup) 목록에서 해당 분반 열기
  2. Zoom 링크, 수업 자료, 주차별 과제 등록·수정
  3. 사이트 분반 상세 → 수업 탭에서 노출 확인
/admin/regulars/classgroup/

D. 출석 반영 (수업 직후)

  1. 일괄: 일상 운영 → 출석 CSV 업로드 — 컬럼 안내 확인 후 업로드
  2. 분반별: 분반 상세의 Zoom 출석 가져오기
  3. 「출석 기록」에서 분반·날짜 건수 검수
  4. 사이트 분반 상세의 「이번 주 출석」·출결 상세가 바뀌었는지 확인
/admin/regulars/attendancerecord/import-csv/
사유폼·수기로 확정된 출석은 Zoom/CSV 재업로드에 덮이지 않는 경우가 많습니다. 숫자가 이상하면 “어떤 경로로 넣었는지”부터 확인하세요.

E. 출결 사유폼 검토 (당일~익일)

  1. 정규반 → 출결 사유 제출 목록
  2. 결석·지각·화면 미공유 등 사유 검토
  3. 벌점 자동 정리는 주기 작업이라 즉시 반영이 아닐 수 있음 (최대 약 1시간)

F. 상벌점

  1. 일상 운영 → 상벌점 CSV 업로드
  2. 회원 식별키·분반·점수·사유를 채운 CSV 업로드
  3. 「상벌점 기록」에서 검수 → 사이트 「내 현재 상태」총점 확인
/admin/regulars/pointrecord/import-csv/

B포인트는 수료 총점과 별개입니다. 지급은 일상 운영 → B 포인트 지급.

G. 주간 점검

  1. 대시보드·지표 → 정규반 운영
  2. 출석률·제출률이 낮은 분반을 찾고, 해당 분반·회원에 안내
/admin/regulars/dashboard/

H. 시즌 — 조별활동 · 블로그 챌린지

  • 조별활동: 정규반 → 조별활동 생성 → 정보 제출 기간 → 자동/수동 팀 매칭 → 일지·채점 → 조장 상점/중도이탈 벌점 액션
  • 블로그: 주제 등록 → 제출 목록에서 스탬프 지급(승인) → (시즌 정책에 따라) 보너스 상점 액션
  • 중도이탈 현황: 대시보드·지표 → 조별활동·중도이탈

6. Learning

드롭다운 공모전 · 클래스 · 코딩테스트 · 자격증 · 수료시험 · 정부교육
탭 목적

정규반 밖 학습 프로그램·콘텐츠 진입점입니다.

사이트 하위

  • 공모전 · 클래스 · 코딩 테스트
  • 자격증 · 수료시험 · 정부교육
어드민에서

Learning 탭 운영 방법

왼쪽 탭 Learning + 승인 대기는 일상 운영

1) 강의·클래스 심사 (공개 전)

  1. 일상 운영 → 강의·클래스 심사 대기 (또는 Learning의 강의 심사 필터)
  2. 콘텐츠 확인 후 승인 / 반려
  3. 승인되면 사이트 Learning·클래스에 노출

2) WAVE·원데이·JOB 단편 심사

  1. 일상 운영 → 단편(WAVE·원데이·JOB) 심사 대기
  2. 검수 후 승인 / 반려

3) 유료 VOD 입금 승인

  1. 일상 운영 → 강의 VOD 입금 승인
  2. 입금 사실 확인 후 승인 → 회원 강의 접근 개방

4) 공모전·스터디·수료시험

  • 공모전 제출·평가: Learning → 공모전 제출 / 평가 시트
  • 스터디: 공지(카테고리 study)·문제·신청·제출 메뉴
  • 수료 시험: 출제·응시 기록 메뉴
담당이 정해진 심사·입금 큐는 임의 승인하지 마세요. 확실하지 않으면 URL과 건 정보를 붙여 확인합니다.

8. Report

Gen Z · Trend Z 등
탭 목적

어드민에서

Report 탭 운영 방법

왼쪽 탭 Report · 또는 커뮤니티 → 공지 (카테고리 Gen Z / Trend Z)

  1. Report 허브 바로가기 또는 공지 목록에서 카테고리 필터

  3. 사이트 Report 탭에서 노출 확인

9. 커뮤니티

/qna/ · /notices/ 공지 · QnA · 자유 · 후기
탭 목적

공지·행사와 QnA/게시판입니다. 행사 신청·승인·안내가 운영 핵심입니다.

어드민에서

커뮤니티 탭 운영 방법

왼쪽 탭 커뮤니티 · 현황은 대시보드·지표 → 행사 신청

1) 일반 공지 / QnA

  1. 커뮤니티 → 공지에서 글 작성 (카테고리·고정·노출 기간)
  2. QnA·자유·후기 글은 커뮤니티 게시판 모델에서 조회·삭제·조치
  3. 사이트 커뮤니티 탭에서 노출·필터 확인

2) 행사 공지 + 신청 받기

  1. 공지 작성 시 행사 설정: 신청 기간, 정원, Zoom 링크·노출 시점 등
  2. 회원이 사이트에서 신청하면 행사 신청 목록에 쌓임
  3. 신청 건을 승인 / 대기 / 취소 처리
  4. 필요 시 Zoom 안내 메일·채팅 초대 메일 일괄 발송

3) 현황 보기
