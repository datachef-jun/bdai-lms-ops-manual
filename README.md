# BDAI LMS 운영진 빠른 시작 메뉴얼

정적 사이트 소스입니다. (비공개 LMS 저장소는 Pages 미지원이라 공개 배포 저장소로 미러합니다.)

- **공개 URL:** https://datachef-jun.github.io/bdai-lms-ops-manual/
- **배포 저장소:** https://github.com/datachef-jun/bdai-lms-ops-manual
- 로컬 미리보기: `python3 -m http.server 8765 --directory ops-manual` → `http://127.0.0.1:8765/`
- 수정: `ops-manual/index.html` 중심으로 섹션 추가 후, 공개 저장소에도 동일 내용 반영하면 Pages가 갱신됩니다.
